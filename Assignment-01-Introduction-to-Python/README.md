# Assignment 01 — Introduction to Python

## 📌 Overview

This assignment introduces fundamental Python programming concepts through a simple product sales analysis program.

The program allows users to input product information, calculate total revenue, categorize sales performance, and generate recommendations based on the sales results.

---

## 🎯 Objectives

The objectives of this assignment are to:

- Understand how to receive user input in Python
- Work with variables and data types
- Perform basic arithmetic calculations
- Use conditional statements (`if`, `elif`, and `else`)
- Build a simple program using logical decision-making

---

## 📚 Topics Covered

### 1. User Input

The program collects the following information from the user:

- Product Name
- Number of Products Sold
- Product Price

Two different approaches are used:

- Using a function
- Using direct manual input
