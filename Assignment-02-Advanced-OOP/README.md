# Assignment 02 — Advanced OOP

## 📌 Overview

This assignment explores fundamental Object-Oriented Programming (OOP) concepts in Python through several practical exercises.

The assignment covers creating classes and objects, protecting data using encapsulation, reusing code through inheritance, modifying method behavior with polymorphism, and implementing abstraction.

---

## 🎯 Objectives

The objectives of this assignment are to:

- Understand classes and objects in Python
- Apply encapsulation to protect object data
- Implement inheritance between classes
- Understand polymorphism and method overriding
- Create and use abstract classes

---

## 📚 Topics Covered

### 1. Class and Object

Creating a `Mahasiswa` class with the following attributes:

- Name
- Student ID (NIM)
- Major

A method is also created to display student information.

---

### 2. Encapsulation

Creating a `Tabungan` class with a private `saldo` attribute.

The class includes methods for:

- Depositing money
- Withdrawing money
- Checking the current balance
- Preventing withdrawals when the balance is insufficient

---

### 3. Inheritance

Creating a `Pegawai` parent class and a `Manager` subclass.

The `Manager` class inherits attributes from `Pegawai` and adds an additional `tunjangan` attribute.

---

### 4. Polymorphism and Method Overriding

Creating different vehicle classes:

- `Kendaraan`
- `Mobil`
- `Motor`

Each class implements the `bahan_bakar()` method with different behavior through method overriding.

---

### 5. Abstraction

Creating an abstract `Hewan` class with an abstract `suara()` method.

The method is implemented differently by:

- `Kucing`
- `Anjing`
