# Assignment 03 — Intermediate Data Types and Structures

## 📌 Overview

This assignment explores intermediate Python concepts and their application in data analysis using the Titanic dataset.

The assignment focuses on identifying different types of data, using looping for data exploration, and applying lambda functions for data manipulation.

---

## 🎯 Objectives

The objectives of this assignment are to:

- Identify continuous and categorical data in a dataset
- Understand nominal and ordinal categorical data
- Use `for` loops and `while` loops
- Apply lambda functions for data manipulation
- Handle missing values
- Transform categorical data into numerical values

---

## 📚 Topics Covered

### 1. Data Type Investigation

Analyzing the Titanic dataset to identify:

- Continuous data
- Categorical data
- Nominal data
- Ordinal data

The analysis uses data types and unique values to better understand the characteristics of each column.

---

### 2. Looping

Using different looping methods:

#### `for` Loop

Displaying column names that begin with a consonant.

#### `while` Loop

Printing odd numbers up to 30 and identifying numbers that are divisible by 3.

---

### 3. Lambda Function

Applying lambda functions for data manipulation:

- Counting missing values (`NaN`) in the `body` column
- Converting `female` to `0`
- Converting `male` to `1`
