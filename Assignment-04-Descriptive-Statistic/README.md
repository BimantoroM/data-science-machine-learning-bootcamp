# Assignment 04 — Descriptive Statistics

## 📌 Overview

This assignment explores descriptive statistics using a self-generated dummy dataset.

The analysis focuses on understanding data characteristics through statistical measurements, relationships between variables, confidence intervals, segmentation, and data visualization.

---

## 🎯 Objectives

The objectives of this assignment are to:

- Generate a dummy dataset using Python
- Perform descriptive statistical analysis
- Analyze relationships between numerical variables
- Calculate expected values and confidence intervals
- Compare statistics across different groups
- Visualize data distributions and relationships

---

## 📊 Dataset

The dataset was generated using Python with 100 observations.

It contains information related to digital behavior, including:

- Age
- Location
- Smartphone Brand
- Digital Interest
- Login Frequency
- Login Duration
- Digital Spending
- Employment Status
- Gender
- Digital Dependency Level

Several derived variables were also created, such as:

- Age
- Average Duration per Session
- Digital Dependency Level

---

## 📚 Topics Covered

### 1. Data Generation

Creating a dummy dataset using:

- NumPy
- Pandas
- Faker
- Random Data Generation

The dataset includes both numerical and categorical variables.

---

### 2. Descriptive Statistics

Calculating:

- Mean
- Median
- Mode
- Variance
- Standard Deviation
- Range

These measurements are used to understand the central tendency and distribution of numerical data.

---

### 3. Covariance & Correlation

Analyzing relationships between numerical variables, including:

- Age vs Digital Interest
- Digital Spending vs Login Frequency
- Digital Interest vs Login Duration

The relationships are evaluated based on direction and correlation strength.

---

### 4. Expected Value & Confidence Interval

Calculating:

- Expected Value
- Mean
- 95% Confidence Interval

This analysis helps estimate the expected characteristics of the data and understand the possible range of the population mean.

---

### 5. Segmentation & Visualization

Comparing data across different groups, such as:

- Digital Interest by Gender
- Digital Spending by Employment Status

Visualizations include:

- Bar Chart
- Histogram
- Boxplot
- Scatter Plot

## 💡 Key Takeaway

One of the most important lessons from this assignment is that data quality and data generation logic can significantly influence statistical results.

When data is generated randomly, relationships between variables may appear weak or insignificant. However, variables created with meaningful relationships can reveal clearer patterns.

This assignment also showed that segmentation is important because overall averages can hide meaningful differences between groups.
